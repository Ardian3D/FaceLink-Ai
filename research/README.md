# Ruang Kajian Jurnal FaceLink AI

Folder ini disiapkan untuk rekan tim yang mengerjakan **kajian jurnal dan tinjauan literatur akademik**. Fokus pengembangan perangkat lunak, arsitektur, API, keamanan, dan IoT ada dalam `docs/` serta source code yang nanti dibuat.

Panduan singkat:

- Catat judul, penulis, tahun, DOI/URL asli, metode, kontribusi, batasan, serta relevansi jurnal yang ditelaah.
- Bedakan kesimpulan penulis jurnal, pendapat tim, dan hasil eksperimen FaceLink AI sendiri.
- Hormati hak cipta artikel. Simpan tautan dan ringkasan sendiri alih-alih mengunggah artikel berbayar tanpa izin.
- Jangan menaruh foto wajah atau data pribadi peserta uji dalam repository.
